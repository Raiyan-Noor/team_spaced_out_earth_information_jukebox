# Use of AI — Earth Jukebox

NASA Space Apps requires every AI tool used in a submission to be named, together with the prompts and the
reasoning. This file is that log. Each entry lists: date, tool, prompt (verbatim when short, otherwise
summarized), what was generated or changed, and what still needs human review.

Humans on the team wrote `CLAUDE.md` (project brief and design decisions) and `docs/SONIFICATION_SPEC.md`
(algorithm spec). Code generated by AI is reviewed by the team before the hackathon.
